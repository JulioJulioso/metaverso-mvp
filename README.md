# Metaverso Sinestesia (sitio publicado)

Rama `gh-pages` del repositorio [metaverso-mvp](https://github.com/JulioJulioso/metaverso-mvp). Solo contiene el build web; el codigo Unity esta en `main`.

GitHub Pages: branch `gh-pages`, carpeta `/docs`. URL: https://juliojulioso.github.io/metaverso-mvp/

`docs/index.html` manda a `desktop/` o a `quest/` segun el navegador. Esas carpetas aparecen despues de `Metaverso > Build Web` en Unity.

No editar a mano. Se publica con `Tools/publish-web.ps1` desde `main`.

Embed para la web del estudio: `embed/iframe.html`. En Quest conviene ademas un enlace directo a la misma URL.
